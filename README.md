# Homebrew Tap for RemarkableSync

[![GitHub](https://img.shields.io/badge/GitHub-RemarkableSync-blue?logo=github)](https://github.com/JeffSteinbok/RemarkableSync)
[![PyPI version](https://img.shields.io/pypi/v/remarkablesync.svg)](https://pypi.org/project/remarkablesync/)

A Homebrew tap for [RemarkableSync](https://github.com/JeffSteinbok/RemarkableSync) — a toolkit for backing up reMarkable tablet notebooks, converting them to PDF, and transcribing handwriting to Markdown with AI.

## Installation

```bash
brew tap JeffSteinbok/remarkablesync
brew install remarkablesync
```

## Upgrading

```bash
brew update
brew upgrade remarkablesync
```

## Usage

```bash
RemarkableSync --help
```

For full documentation, see the [main repository](https://github.com/JeffSteinbok/RemarkableSync).
